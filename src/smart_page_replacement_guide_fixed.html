01 / The concept

What is page replacement?

Programs use pages of memory. If a requested page is not in RAM, a page fault occurs. When every available frame is occupied, the operating system must select a page to remove.

STEP 01

Request a page

The program asks for the next page in its reference string.

STEP 02

Check the frames

If the page is present, it is a hit. Otherwise, it is a page fault.

STEP 03

Replace if needed

If no empty frame remains, an algorithm selects a page to remove.

02 / The strategies

Three classic algorithms

Each algorithm uses a different rule to choose a victim page. Results depend on the reference string and frame count.

ALGORITHM 01

FIFO

First In, First Out. Replaces the page that has been in memory the longest. Easy to understand and implement.

Arrival order
ALGORITHM 02

LRU

Least Recently Used. Replaces the page that has not been accessed for the longest time in the past.

Recent history
ALGORITHM 03

Optimal

Replaces the page whose next use is farthest in the future. It is a benchmark because real systems cannot know the future.

Future reference
